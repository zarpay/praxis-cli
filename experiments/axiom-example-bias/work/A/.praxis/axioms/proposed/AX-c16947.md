Input validation must follow a logical sequence: check for presence of required fields, then type correctness, then business rule compliance. This ordering ensures clear, progressive validation that catches fundamental problems before evaluating complex constraints.

## Violating example

const parlors = store.listParlors(); if (!input.subject) return { ok: false, error: 'missing subject' };

## Compliant example

if (!input.subject) return { ok: false, error: 'missing subject' }; if (typeof input.minReviews !== 'number') return { ok: false, error: 'minReviews must be a number' }; const parlors = store.listParlors();
