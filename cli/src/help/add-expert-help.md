When to use: starting a new expert — an agent identity with a defined
scope, responsible for the files its validates: governs.

Behavior:
  Scaffolds into the configured expertsDir with the frontmatter the
  compiler and the eval layer honor: validates: (compiled out as the
  spec's paths: targeting), excludes:, context: (assist material), and
  practices: (the procedures the expert references). The body's
  placeholders are authoring guidance to replace by hand; the file
  compiles once `praxis compile` runs.

Example:
  $ praxis add expert service-steward

Next:
  praxis compile   compile the finished expert into a profile
  praxis status    flags dangling refs and zero-match globs
