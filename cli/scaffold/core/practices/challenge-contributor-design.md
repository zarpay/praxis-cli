# Challenge Contributor Design

> Own the creation and management of experts and practices — with a critical eye throughout.

## Objective

Ensure every expert and practice is truly needed, well-scoped, and properly contextualized.

## Process

### 1. Challenge the Need
- What problem does this solve?
- Can existing experts cover this?
- Is this an expert, or just a practice?

### 2. Demand Clear Boundaries
- What is this expert responsible for?
- What is this expert NOT responsible for?
- What authorities does this expert have?

### 3. Validate Context References
- All experts should reference Constitution
- Add relevant conventions, lenses
- Don't over-reference

### 4. Create the Documents
- Follow templates exactly
- Update practices-index

## Criteria

- [ ] Proposal challenged — need is validated
- [ ] Scope is explicit (Responsible For / Not Responsible For)
- [ ] Boundaries prevent overlap with existing experts
- [ ] Documents follow templates and conventions
- [ ] Ownership table is updated
