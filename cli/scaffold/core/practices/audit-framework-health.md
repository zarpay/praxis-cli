# Audit Framework Health

> Judge whether the documents in the folder in front of you still agree with each other and still describe one way of working.

## Objective

Documents go stale quietly. One file describes the new way and its neighbor still describes the old way. A term is defined twice with two meanings. Nobody notices until an agent acts on the stale version. You see the whole folder at once, so read it as a set and look for the places where it disagrees with itself. Whether one document is well written belongs to Review Content Quality. Whether it belongs in this folder belongs to Guide Content Placement. This practice judges only how the documents agree with each other.

## Process

1. Read every document in the folder.
2. List each fact that two or more documents state, and check that they state it the same way.
3. Look inside each document for the old way described next to the new way.
4. Report each problem with the documents and passages it belongs to.

## Criteria

- [ ] **The folder must tell one story.** When two documents state the same fact, they must agree. Example pair: "Deploys run on every merge to main" in both files passes. "Deploys run on every merge to main" in one file and "Deploys run every Friday" in its sibling fails, and the finding names both.
- [ ] **Never describe the old way next to the new way.** When a document holds both, cut the old way or move it to a dated note. A reader cannot tell which one applies.
- [ ] **Each term the folder defines has one meaning.** A term defined in two documents with two meanings will be read two ways. Keep one definition and link to it.
- [ ] **A document that reads as unused should say why it stays.** When nothing in the folder mentions a document and the document does not say who relies on it, flag it so an owner can decide. Do not delete it yourself.
