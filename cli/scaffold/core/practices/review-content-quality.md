# Review Content Quality

> Judge whether each document in the folder in front of you can be understood by a reader who has nothing else.

## Objective

Praxis documents are loaded into agents and read by new team members. Neither can ask the author what was meant. Every document has to make sense on its own, say what it needs to say, and stop. You see the whole folder, so you can also tell when a document leans on a sibling that does not say what it claims.

## Process

1. Read each document as someone who has never seen this project.
2. Note each place where you need outside knowledge to follow it.
3. Note each sentence that could be cut without losing meaning.
4. Report each problem with the document and passage it belongs to.

## Criteria

- [ ] **Each document stands on its own.** A reader with only this file must be able to follow it. Define a term, or link to where it is defined. "Run the usual checks before merging" fails, because the reader has to guess what the usual checks are. "Run the test suite and the linter before merging" passes.
- [ ] **Every sentence earns its place.** Cut words that add no meaning. A long document is read less carefully than a short one. Never pad a section to make it look complete.
- [ ] **Each document says what to do, not only what is true.** A reader must know what changes for them after reading. A page of facts with no "so what" fails.
- [ ] **A link to a sibling in this folder points at what the link claims.** A link is a promise about what is on the other end. When the target is in front of you, check that it keeps the promise. Do not judge links to files you cannot see.
