# Guide Content Placement

> Judge whether every document in the folder in front of you belongs there.

## Objective

Praxis has four primitives: context, experts, practices, and reference. Each answers a different question. A document in the wrong folder is hard to find and gets loaded at the wrong time. You see a whole folder at once. Judge each document by the question it answers, and judge the folder by whether its documents answer the same question.

## Process

1. Name the question this folder answers: who we are (context), who you are (experts), what you own (practices), or what things mean (reference).
2. Read each document and name the question it answers.
3. Compare the documents to each other. Look for two that say the same thing.
4. Report each problem with the document and passage it belongs to.

## Criteria

- [ ] **Each document answers this folder's question.** A constitution file says who we are and what we value. A convention says how we do things. A reference says what a term or thing means. A file that mixes them must be split. A constitution file that says "We value honesty and care" passes. A constitution file that says "We value honesty, and all filenames use kebab-case" fails, because the second half is a convention.
- [ ] **Each document fits its subfolder.** Under context/, the constitution holds what rarely changes, conventions hold standards, and lenses hold ways of thinking. A standard filed under constitution will be treated as fixed when it should evolve.
- [ ] **No two documents in the folder say the same thing.** Two copies drift. When two documents share a passage, one of them must link to the other. Do not keep both.
- [ ] **Each filename says what the document is about.** A reader scanning the folder should know what is inside without opening it. "documentation.md" tells them. "misc.md" does not.
