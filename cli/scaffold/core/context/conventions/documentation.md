# Documentation Convention

> How every document in this framework is written.

## Who reads these documents

Every document here is loaded into agents and read by new team members. Neither can ask the author what was meant. Write so that a reader with only this file can follow it.

## Writing

- Say what a reader is meant to do after reading, not only what is true.
- Use short sentences and plain words. Cut every word that adds no meaning.
- Define a term where you use it, or link to where it is defined.
- Put examples in the document itself. Never point to a live file as the example, because that file will change.

## Format

- Markdown with YAML frontmatter. Every document type has required frontmatter fields; include them.
- Filenames in kebab-case that say what the document is about.
