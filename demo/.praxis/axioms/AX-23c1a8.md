Every file in a feature directory must be reachable from index.ts through its import graph. Files that are not imported (directly or transitively) by the entry point are orphaned and indicate either dead code or an incomplete public API. This ensures all code in the feature serves its declared capability.

## Violating example

A feature directory contains index.ts that imports flavor.ts, but also contains old-rotation.ts which is not imported by any file in the feature.

## Compliant example

A feature directory contains index.ts that imports flavor.ts, which in turn imports helpers.ts and flavor-of-day-types.ts, making all files reachable through the import graph.
