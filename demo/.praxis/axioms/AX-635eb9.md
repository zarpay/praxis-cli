Test data must be built fresh inside each test or its describe setup; test suites must not depend on existing state from other tests or external sources. Each test scenario should establish its own required data independently.

## Violating example

// Assuming store already has data from previous tests or setup
it('returns true', () => {
  expect(sendNewsletter(...)).toBe(true);
})

## Compliant example

describe('when subject is valid', () => {
  beforeEach(() => {
    // Build fresh test data for this scenario
    store.clear();
    store.addParlor({ id: 'parlor-1', name: 'Test Parlor' });
  })
  
  it('returns true', () => {
    expect(sendNewsletter(...)).toBe(true);
  })
})
