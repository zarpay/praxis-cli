A service module must export exactly one entry point: a function named `run` that takes its dependencies (Store first) and a single input object, returning a `Result<T>` from the domain types. The function must be named `run` (not any other name), must return the domain `Result<T>` type (not boolean, void, or any other type), and must import the Result type from the domain module.

## Violating example

A service file exports `sendNewsletter(store, input)` returning `boolean`, with no import of domain Result type.

## Compliant example

A service file exports `run(store: Store, input: NewsletterInput): Result<NewsletterSent>` with `import { Result } from '../domain/types.js'`.
