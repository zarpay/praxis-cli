Every service's doc comment must state its purpose clearly and enumerate all domain failure modes completely, so a caller can handle every error without reading the body.

## Violating example

export function run(store: Store, input: Input): Result<Output> { ... }

## Compliant example

/**
 * Creates a new review for a parlor.
 * Fails if: rating is out of range, parlor does not exist, user has already reviewed this parlor.
 */
export function run(store: Store, input: Input): Result<Output> { ... }
