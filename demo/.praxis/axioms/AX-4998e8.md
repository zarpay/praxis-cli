A feature directory must contain exactly one entry point file named index.ts that re-exports the feature's entire public API. Nothing outside the feature may import any other file in it. This ensures a clear, controlled interface boundary for each feature.

## Violating example

A feature directory src/features/flavor-of-day/ contains flavor.ts and old-rotation.ts but no index.ts file.

## Compliant example

A feature directory src/features/flavor-of-day/ contains index.ts that exports { run } from './flavor' and { RotationConfig } from './flavor-of-day-types', establishing the public API.
