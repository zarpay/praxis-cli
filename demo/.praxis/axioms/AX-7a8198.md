Logic file names in a feature directory must describe the action the file performs, not merely name the entity or noun involved.

## Violating example

Logic files named flavor.ts or old-rotation.ts (noun-first) in a feature directory.

## Compliant example

Logic files named get-flavor.ts, announce-flavor.ts, or rotate-flavors.ts (verb-first kebab-case) in a feature directory.
