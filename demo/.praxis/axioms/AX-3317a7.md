Services must classify failures semantically: any failure a caller could plausibly cause (invalid input, missing data, business rule violations) must be returned as a domain failure value; exceptions are reserved exclusively for programmer errors (type violations, null references, broken invariants).

## Violating example

if (!input.subject) { throw new Error('bad subject'); }

## Compliant example

if (!input.subject) { return { ok: false, error: 'subject must not be empty' }; }
