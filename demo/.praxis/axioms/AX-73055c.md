A feature directory must contain a dedicated types file named <feature>-types.ts where all type definitions for that feature live. This separates interface contracts from implementation and provides a clear location for type definitions.

## Violating example

A feature directory src/features/flavor-of-day/ contains flavor.ts with inline type definitions but no flavor-of-day-types.ts file.

## Compliant example

A feature directory src/features/flavor-of-day/ contains flavor-of-day-types.ts that exports type FlavorConfig and interface DaySchedule, with flavor.ts importing these types.
